# External specifications

対象version・確認日を固定し、公式ドキュメント、公式repository/releaseを優先する。
大会SWルールはroot AGENTS.mdにある公式ページを参照する。
検索結果だけで確定せず、根拠ページを開いて該当記述を読む。

確認できた仕様、推測、TBDを分け、結論の近くに根拠URLを付ける。
2025由来の現行仕様を2026の確定仕様として扱わない。
調査だけなら影響と未確定事項を報告する。実装を伴う依頼では、関連する
`docs/spec/`または`docs/interface/`を更新してから依頼範囲の実装へ進む。

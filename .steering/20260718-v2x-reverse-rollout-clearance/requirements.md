# Requirements

## 背景

`output/20260718-174716` の dev3 走行では、D3 の壁接触を起点に D1、D2 が順次停止した。
3台とも復帰距離 `0.000 m`、`step=0/10` のまま `rear_vehicle_blocked` から
`clearance_wait_timed_out` へ遷移した。

共通コース進捗では D3 <- D1 <- D2 の順で、D2 は最後尾だった。それにもかかわらず、
現在の軸平行なV2X回廊は前方のD1まで後退障害物として扱った。前端1.49 m、margin 0.05 m、
他車半径1.45 mの和により、前方約2.99 m以内の停止車が後退回廊へ重なるためである。

## 必須要件

1. 選択された復帰ロールアウト全体に沿ってV2X車両とのクリアランスを評価する。
2. 保守的な車両円が初期姿勢ですでに重なる場合、後退によって重なりが単調に減少する
   逃避だけを許可する。
3. 後方車へ近づく後退、途中で新しい重なりを生じる旋回、初期重なりを悪化させる操作は拒否する。
4. V2X message欠落、不正位置、不正速度、position jumpは従来どおりfail closedとする。
5. 動いている他車には従来の予測回廊を維持し、今回の緩和を停止列に限定する。
6. ブロックした車両ID、判定方式、初期・最小・最終クリアランス、拒否距離をログへ残す。
7. ROS topic、message、Domain、gear、安全上限、提出物の契約は変更しない。

## 非要件

- 車両半径を小さくして安全余裕そのものを減らすこと。
- `clearance_wait_timeout_sec` を延ばすだけの対症療法。
- Domain 0、AWSIM reset、teleport、評価FSMの変更。
- 実車での後退有効化。

## Definition of Done

- 前方停止車との保守的な初期重なりから離れる後退を許可する単体テストが通る。
- 後方停止車へ近づく後退と、新規接触を生むロールアウトを拒否する単体テストが通る。
- `multi_purpose_mpc_ros` がビルドでき、関連テストが通る。
- dev3で最後尾から順に復帰が進むか、進まない場合はブロッカーを特定できるログが残る。

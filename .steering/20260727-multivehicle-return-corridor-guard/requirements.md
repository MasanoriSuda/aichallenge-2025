# Requirements

## 目的

P1 がロック対象車を抜いた直後、別のV2X車両が復帰経路を占有しているにもかかわらず
`Pass -> Return` へ移行し、接触・SafetyBrake・停止復帰へ至る事象を防ぐ。

## 対象

- `Pass -> Return` 前に、ロック対象以外を含む全V2X車両で復帰経路の占有を確認する。
- Return開始直後に別車両が復帰経路へ入った場合は、進行が浅い間だけPassへ戻す。
- 復帰待ち中は無制限に加速せず、既存のRecovery速度を上限として使う。
- 直前の3パラメータ実験は、追い越し到達率と壁余裕違反を悪化させたため元の値へ戻す。

## 制約

- 物理的な壁接触と緊急制動は従来どおり最優先する。
- ロック対象車の後方クリア条件は維持する。
- ROS 2 topic、message、serviceの契約は変更しない。
- `aichallenge/result-summary.json` のユーザー変更には触れない。

## 完了条件

- 復帰経路占有判定の純粋ロジックを単体テストできる。
- 別車両が復帰経路を占有している間はReturnへ入らない。
- 復帰経路が空けばReturnへ進める。
- 対象パッケージがビルドできる。

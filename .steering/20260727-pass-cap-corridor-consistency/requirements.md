# Requirements

## 目的

低速車の追い越し中に、横離隔判定の微小な揺れで速度 cap が再適用されて追い越しが長期化し、そのまま壁制約による Recovery に入る負のループを減らす。

## 対象

- Pass 速度 cap の解除判定に限定的なヒステリシスを追加する。
- 固定 corridor goal と、ロック対象車に対する最低横離隔の整合を取る。
- Pass が実質完了して対象車が後方にいる場合、壁余裕 Recovery より Return を優先する。
- 状態変化時だけ診断ログを出す。

## 制約

- 既存の速度値、壁接触判定、緊急制動判定は緩和しない。
- 横離隔が大きく崩れた場合は速度 cap を再適用する。
- 車両間 corridor と start-grid breakout の既存契約は維持する。
- ROS 2 topic / message / service の契約は変更しない。

## 完了条件

- 純粋ロジックの単体テストが追加され、通る。
- `multi_purpose_mpc_ros` がビルドできる。
- 設定値と試走で確認すべきログが明記される。

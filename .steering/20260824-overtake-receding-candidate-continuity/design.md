# Design

## Investigation gate

Before changing horizon behavior, extend the existing build rejection with the
exact physical interval, interval width, requested reserve and canonical
intent. This is diagnostic provenance, not a new runtime decision.

## Candidate repair direction

If H1 is confirmed, represent the canonical artifact as the exact physically
proven receding prefix. Its horizon and validity must be derived from the same
tactical certificate; an unproven tail must not be appended merely to keep the
configured global `N`.

The bounded prefix must retain:

- current target and observation identity;
- committed side and Mission generation;
- five-state formulation and hard tracking tube;
- exact wall/target proof;
- an explicit prefix end which prevents execution past the certificate.

It must not gain rear-clear/Return authority unless those stages were actually
proven. The following tactical update replaces the prefix atomically with a new
canonical artifact.

If H2 is confirmed instead, the current candidate is genuinely infeasible and
must not be published. The repair target then becomes upstream side/horizon
selection, not proof weakening.

## Scope boundary

This Slice does not alter Follow, Emergency, Recovery, parameters or solver
tuning. Pre-entry physical rejection remains fail-closed unless evidence proves
that it shares the same horizon-lineage defect.

## Implemented ownership rule

- Only active `ShiftOut`, `Pass` and `Return` execution contexts may publish a
  bounded canonical prefix. Track, Cruise, Follow and pre-entry geometry retain
  their configured horizon unless the pre-entry branch itself builds a bounded
  five-state QP.
- State zero remains the observed equality. Every future state must carry the
  unchanged hard tracking reserve.
- The first future state which cannot carry that reserve terminates the prefix;
  fewer than two executable transitions is rejected.
- The effective QP horizon owns all downstream shapes: warm-start identity,
  context fingerprint, primal normalization, actuation extraction, exact wall
  proof, target proof, terminal metrics and canonical plan extraction.
- Canonical validity ends at the bounded prefix duration. Retained execution
  may not advance past that end.

The repair does not reinterpret a prefix as a completed Mission.  Mission
phase, target, side and generation remain supervisor state; the next current-
world solve replaces the bounded artifact atomically.

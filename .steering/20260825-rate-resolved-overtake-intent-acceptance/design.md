# Design

## Validation flow

For every observed intent transition, join these records by decision,
generation, target, side, problem, solution, plan, and certificate:

1. V2X behavior and OvertakeLine phase transition;
2. canonical execution identity source;
3. atomic transition admission, when required;
4. six-state artifact and exact physical-wall certificate;
5. retained current-world result;
6. final MPCC execution contract;
7. subsequent phase transition or explicit Emergency/Recovery reason.

## Decision rule

An explicit wall, dynamic-obstacle, semantic-artifact, or solver rejection is
not bypassed. It is inspected to determine whether producer and consumer used
the same immutable context. Only a context/ownership mismatch permits a code
change in this Slice. A genuinely infeasible candidate remains fail-closed and
is recorded for later path-quality work after legacy deletion.

## Completion boundary

This Slice validates the new normal owner. It does not tune Overtake quality or
delete broad legacy infrastructure merely because the source is now
unreachable. Physical deletion is a separate Slice with source-contract tests
and an explicit deletion ledger.

## Confirmed ownership defect

The pre-entry branch artifact is a five-state tactical artifact.  It proves the
selected target, side, Mission generation, lifetime, and tactical path.  It is
not the live steering producer after `bfd0b4f` promoted Overtake to the shared
six-state steering-rate MPCC.

The old pre-entry resolver nevertheless extracted the first five-state
actuation and rejected the intent when that steering was not reachable from the
current steering state.  This rejected the intent before the six-state producer
could solve and perform its own atomic physical admission.  It was therefore a
second live-actuation authority, not a safety proof belonging to the tactical
artifact.

The correction keeps semantic identity and lifetime validation of the selected
tactical artifact, but removes five-state actuation extraction, steering
continuity admission, and installation into the retired five-state production
plan store.  The six-state producer remains solely responsible for live
actuation, exact physical proof, retained current-world proof, and publication.

# Design

The 16-stage experiment demonstrated that reducing mandatory canonical work
can improve the computation tail, but it removed too much terminal successor
visibility.  Eighteen stages retains 90% of the baseline horizon while
reducing every initial, relinearized, wall-refined, and dynamic-refined QP.

This is still a single-family A/B.  Tactical lookahead remains independent,
and the complete 18-stage execution artifact remains physically certified
before publication.  Dynamic phase completion, not fastest lap, decides
acceptance.

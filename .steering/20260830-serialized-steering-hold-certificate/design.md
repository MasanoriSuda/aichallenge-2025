# Design

## One publication-boundary rule

For elapsed time `t < publication_interval_sec`:

- acceleration = current serialized acceleration;
- steering angle starts at the current serialized tire angle;
- steering rate = 0 because no rate command is published.

After the boundary, future SQP controls may again use their internal steering
rate as a model of subsequent angle commands.

The integration step is already split exactly at the publication boundary, so
the rule requires no time tolerance or new scheduling state.

## Normal continuation

`build_continuation()` uses a copy of the current control with zero steering
rate while the exact rollout is inside the publisher interval. The exact
nonlinear state remains the sole source of stage-end steering.

## Terminal Stop

`build_stop_contingency()` uses zero steering rate for its first serialized
command interval. Its later braking/path-tracking suffix retains the existing
Stop lateral policy. The recorded actuation trace exposes the held angle.

## Safety effect

This is not a relaxation. A wall proof can become either feasible or
infeasible because it now checks the path generated by the command actually
sent. The old proof is discarded rather than grandfathered.

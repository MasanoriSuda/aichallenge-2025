# E2E spatial-authority time-series audit requirements

## Objective

Classify the rejected authority run before changing model architecture or
authority magnitude.

## Questions

1. Did the spatial model request the same steering direction as the admitted
   successor teacher before wall contact?
2. Did the model change direction too late when the opening changed?
3. How often did the existing 0.12 rad authority truncate a correct request?
4. Would a larger global bound improve the causal failure prefix in principle,
   and what normal-state risk would it expose?

## Frozen contracts

- analyze the exact v2 candidate used in the failed run;
- use only samples preceding the one-second contact exclusion boundary;
- do not change runtime weights, flags, limits or launch;
- a bound sweep is diagnostic and may not authorize parameter tuning by itself.

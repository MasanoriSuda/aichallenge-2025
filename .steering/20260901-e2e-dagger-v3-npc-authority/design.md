# Design

Run the deterministic runtime-NPC scenario with v3 explicitly connected to
the existing limited authority.  Compare Finish, wall/crash penalties, motion
stall and spatial inference statistics with the v2 failure reference.

If v3 succeeds, retain it as an experimental NPC candidate and collect an
independent repeat before considering a default.  If it fails, extract the
causal prefix and decide between data coverage, temporal representation and
longitudinal/lateral authority mismatch from evidence.

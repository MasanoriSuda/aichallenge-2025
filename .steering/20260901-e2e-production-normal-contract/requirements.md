# E2E production-normal evidence contract

## Objective

Replace the invalid normal-anchor corpus derived from gap-teacher rollouts with
run-disjoint evidence generated by the frozen production controller itself.

## Frozen identity

- controller: `tiny_lidar_net`
- control mode: `fixed_lidar_brake`
- checkpoint SHA-256:
  `de5f156b271e292a7457d6c474de1267c0a0cf086c428ae5e6f8de4c5a0f4faa`
- residual authority: disabled

## Admission requirements

Each source run must independently prove all of the following:

1. `e2e-competition-analysis.json` has status `pass`.
2. Runtime mode and installed checkpoint match the frozen identity.
3. The requested domain finished every required lap with zero penalties.
4. Motion admission reports no disallowed low-speed or positive-acceleration
   stall interval.
5. The finalized rosbag contains finite 750-point LiDAR scans and synchronized
   longitudinal speed with at most 50 ms timestamp error.
6. A physical run may appear in exactly one dataset split.

## Constraints

- Source steering commands are not labels.  The label is zero correction from
  the frozen controller that successfully produced the run.
- Gap-teacher and DAgger runs are not production-normal evidence.
- Generated bags and datasets remain outside Git.
- No candidate is connected to runtime until independent run-disjoint gates
  pass.

## Definition of Done

- At least one admitted frozen-production run exists in both train and
  validation splits.
- The builder rejects failed, penalized, wrong-mode, wrong-checkpoint and
  split-reused runs before reading training samples.
- Dataset metadata binds every sequence to its run, competition report,
  result detail, bag and frozen checkpoint.
- One bounded offline candidate is reevaluated on the corrected contract; a
  rejection leaves production unchanged.

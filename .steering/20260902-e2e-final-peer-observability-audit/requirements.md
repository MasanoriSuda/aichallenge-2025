# Requirements

## Objective

Determine why successful final-peer supervision does not improve material
corrections under controlled recurrent training.

## Constraints

- Diagnostic only: no model training, packaging, runtime authority or teacher
  threshold change.
- Audit the current peer-augmented recurrent corpus against the immutable
  production-normal corpus.
- Use packaged spatial-v11 identity and report projected, full-conv5 and
  physical-geometry conflicts separately.
- Admit the teacher's 0.100 s causal speed contract only through an explicit
  audit option; preserve the 0.050 s default.

## Definition of Done

- Report exact corpus and candidate identities.
- Quantify material/normal overlap and per-sequence conflict.
- Compare with the previous precontact-teacher observability audit.
- Classify whether the next change belongs to data labels, input state or
  training objective; do not tune a model in this Slice.

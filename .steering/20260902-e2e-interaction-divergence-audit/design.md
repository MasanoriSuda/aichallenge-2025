# Design

Add one offline timeline audit over immutable bags.  It replays the exact
packaged spatial artifact and the diagnostic pre-contact teacher on each LiDAR
frame, aligns wheel speed and the published command causally by recorded time,
and emits contiguous side-hazard episodes.

For each case the report distinguishes:

- the interval before the first sustained low-speed failure;
- a named comparison window: the ten-second causal precursor for a stalled
  domain, or the first 60 seconds after motion for a clean domain;
- post-failure samples, which cannot establish collision causality;
- the teacher's physical escape sign from left/right side clearance;
- current commands that point toward the detected side obstacle;
- current commands that are materially weaker than the teacher projection;
- escape-side flips within one contiguous hazard episode while the vehicle is
  still moving; separate episodes and recorder gaps are never joined.

The same measures are required for clean d3/d4.  A failure-only deficit
supports a model/data defect.  A deficit common to clean passages rejects the
teacher projection as a direct production target.  A side flip before failure
supports a missing temporal commitment hypothesis.  No runtime authority is
changed by this diagnostic.

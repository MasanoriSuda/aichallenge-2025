# Design

This is a qualification Slice, not a tuning Slice.  It returns production to
the simplest already-qualified owner: packaged raw TinyLidarNet plus the
packaged spatial steering adapter.  The recurrent process implementation may
remain unreachable behind explicit experiment arguments, but no recurrent
artifact, process or authority may exist in a default launch.

The dynamic order is deliberately sequential:

1. start a default `make e2e-single` run with no TinyLidar experiment
   environment;
2. require Finish, zero penalties, zero stall, exact runtime configuration and
   no recurrent runtime activation;
3. only then run the deterministic three-vehicle student audit and evaluate d3;
4. create and inspect the submission archive from the same source tree.

Results are compared with the accepted authority-disabled process baselines,
but the purpose is reproducibility and package identity rather than claiming a
small timing improvement.  The earlier four-vehicle/six-lap wall interaction
failure remains a known competition-quality limitation unless a new unchanged
default run disproves it; it is not hidden by this freeze.

# Stateless successor generation

After an exact stateless sibling crosses the only publisher, its existing
encounter identity must remain eligible to request a Pass/Return problem even
though obsolete frozen Mission geometry has been retired. This is draft
eligibility only. Every successor still requires fresh target provenance,
causal serialized predecessor, seven-state solve, full physical certification
and current-world Gate A before any live phase/command transfer.

No new authority, timeout, retention, margin, solver or configuration change.
